# 异环自动钓鱼

《异环》游戏钓鱼小游戏自动辅助工具。通过屏幕捕获识别钓鱼条的绿区和光标位置，自动按键使光标保持在绿区中心。

## 环境要求

- Windows 10/11
- Python 3.10+

## 安装

```bash
pip install -r requirements.txt
```

## 使用方法

1. 启动游戏并进入钓鱼状态
2. 运行脚本（需要管理员权限，会自动请求提权）：

```bash
python 自动钓鱼.py
```

3. 脚本会自动找到游戏窗口并开始工作，按 `Ctrl+C` 退出

## 原理

- 使用 Windows Graphics Capture 后台截取游戏画面
- 通过颜色匹配定位钓鱼条的绿区范围和光标位置
- 根据光标与绿区中心的偏移自动发送 A/D 按键修正

## 注意事项

- 游戏窗口不能最小化（可以在后台）
- 需要管理员权限才能向游戏窗口发送按键
